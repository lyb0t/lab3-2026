# Лабораторная работа №3: Линейные модели

## 1. Данные и подготовка
*   **Линейная регрессия:** Использован датасет `Student_Performance.csv`. Признак `Extracurricular Activities` закодирован бинарно (Yes=1, No=0). Все признаки масштабированы с помощью `StandardScaler` для стабильной работы градиентного спуска.
*   **Логистическая регрессия:** Использован датасет `german.csv` (разделитель `;`). Целевая переменная `Creditability`. Признаки также стандартизированы.

## 2. Гипотезы и эксперименты
*   Реализован градиентный спуск для линейной регрессии (функция потерь MSE, learning_rate=0.05, 800 эпох).
*   Реализован градиентный спуск для логистической регрессии (функция потерь бинарная кросс-энтропия, learning_rate=0.1, 1000 эпох).
*   Сравнение проводилось с готовыми моделями `LogisticRegression`, `DecisionTreeClassifier` и `KNeighborsClassifier` из `sklearn`.

## 3. Метрики
*   **Линейная регрессия:** Итоговый MSE на тестовой выборке составил **4.0826**.
*   **Логистическая регрессия (своя):**
    *   ROC-AUC: **0.7919**
    *   Accuracy: **0.755**
    *   Precision: **0.7834**
    *   Recall: **0.8913**
    *   F1-score: **0.8339**
*   **Сравнение моделей:**
    *   Своя логистическая регрессия: ROC-AUC **0.7919**, F1 **0.8339**.
    *   Decision Tree: ROC-AUC **0.7155**, F1 **0.7938**.
    *   KNN: ROC-AUC **0.7483**, F1 **0.8123**.

## 4. Выводы
Собственная реализация логистической регрессии показала лучший результат (ROC-AUC 0.7919) по сравнению с Decision Tree и KNN на данном разбиении. Это объясняется тем, что данные хорошо разделимы линейной границей, а деревья и KNN склонны к переобучению на шумных признаках кредитного скоринга. Линейная регрессия показала низкий MSE (4.08), что говорит о хорошей сходимости градиентного спуска.

## 5. Воспроизводимость
Все результаты получены при `random_state=42` для разделения данных и инициализации моделей. Код запускается скриптом `check.py`.
